📖 Linear Graph Field Notes
Quick reference guide for straight line graph rules and Cartesian planes:

1. Cartesian Plane & Coordinates

Coordinates are written as (x, y).

x = horizontal distance (left is negative, right is positive).

y = vertical distance (down is negative, up is positive).

Quadrants: I (+,+), II (-,+), III (-,-), IV (+,-).

2. Gradient (m) - Measure of Steepness

m = rise / run = (y₂ - y₁) / (x₂ - x₁)

• Positive: Slants upwards from left to right ↗

• Negative: Slants downwards from left to right ↘

• Zero: Flat horizontal line ➔

• Undefined: Vertical line ⬆

3. Gradient-Intercept Rule: y = mx + c

• m = the gradient (coefficient in front of x).

• c = the y-intercept (where line cuts y-axis, when x = 0).

Caution: If given y = c + mx, the coefficient of x is always m!

4. Constant Rate Problems

When a quantity changes at a constant rate, it forms a linear equation:

Amount = Starting Value ± (Rate × Time)
